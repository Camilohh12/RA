# 📱 Aplicación de Realidad Aumentada

Aplicación móvil de Realidad Aumentada para Android que permite elegir modelos 3D desde un catálogo y colocarlos en el entorno real usando la cámara del celular.

## 🎥 Demo


https://github.com/user-attachments/assets/f054c5b3-0268-4463-a8ec-e33588d83616


## ✨ Funcionalidades

- Detección de superficies reales (piso y mesas) con ARCore
- Indicador visual que muestra dónde se colocará el objeto
- Catálogo de modelos 3D para elegir qué colocar
- Colocación de varios objetos en la misma escena, visibles desde cualquier ángulo
- [Opción para eliminar objetos de la escena: borra esta línea si no aplica]

## 🛠️ Tecnologías

- **Unity 3D** con **C#**
- **AR Foundation** + **ARCore** (Google)
- Compilado para Android (IL2CPP, ARM64)

## 📱 Requisitos

Celular Android compatible con ARCore ([ver lista de dispositivos](https://developers.google.com/ar/devices)).
